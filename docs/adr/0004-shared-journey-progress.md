# 滿版展示與鏡頭共用旅程進度

18 站滿版重製需要在捲動途中停住鏡頭、展開卡牌，並支援快速跨站、反向返回、地圖跳站及面板恢復。現行 `town.js` 由展示區 DOM 位置推算旅程；卡牌不再沿長頁面排列後，這個位置來源不足以表達移動與停留。

採用以可配置的移動／停留區間建立共用旅程進度，由原生捲動提供輸入，同一份解析結果驅動 3D 鏡頭與卡牌舞台。地圖、圖鑑及網址錨點共用跳站入口；開場下降有明確的相機交接。卡牌繼續使用凍結的 DOM 元件，維持既有閃卡、焦點與捕捉行為。

此方案增加旅程狀態與位置恢復的責任，但可使卡圖載入、對話長度及面板開關不再改變飛行距離。保留舊 DOM 高度推算會使滿版版型與相機繼續互相牽動；全面攔截滾輪逐站前進則違反已定案的自然捲動。將卡牌改成 3D 物件也無法直接沿用凍結效果與操作。

2026-09-08 已驗證第 1／9／18 站的共同進度、放大與捕捉、地圖第 16 站、瀏覽器歷史及每站選卡恢復，接受此決策。完整 18 站、87 張卡牌已通過瀏覽器流程驗證。使用者後續要求捲動更流暢，到站輕快浮現：平滑集中在共同旅程輸入（約 90ms 時常），場景直接取同一解析結果，不另加鏡頭追趕延遲。快速跨越超過一站時直接同步目的地。

純進度、指定站落點、歷史恢復及平滑收斂由 `tests/timeline.test.mjs` 驗證。規劃與實測限制見 [UI 重製計畫](../UI-REMAKE-PLAN.md) 及 [驗證記錄](../UI-REMAKE-QA.md)。
