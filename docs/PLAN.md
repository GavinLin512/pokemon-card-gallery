## 1. 目標

把 simeydotme/pokemon-cards-css 的閃卡效果，包裝成一個以「動畫版真新鎮」為背景、全繁體中文、

### 6.2 搜尋框

- 保留在 TopBar。placeholder：「輸入英文名稱，例如：Pikachu」。
- 查詢：`POST https://api.tcgdex.net/v2/graphql`，每個名稱一個別名區塊
  `cards(filters: { name: "{q}", id: "swsh" }, pagination: { page: 1, count: 100 })`，名稱為不分大小寫的子字串比對，
  `id` 含 `swsh` 對應劍盾系列。回應由 `src/config/tcgdex.js` 轉成 pokemontcg.io 格式（集號、卡號、稀有度、subtypes、圖片），
  前端依集號發行順序排序後取前 36 張；轉換規則與驗證結果見 ADR-0003。免金鑰。輸入至少 3 字元，666ms debounce（與原作相同）。
- 卡圖：優先 TCGdex webp；TG、GG、SV 畫廊集與部分促銷卡 TCGdex 沒有圖片，退回 `images.pokemontcg.io`。
  搜尋結果縮圖用 `low.webp`，放大用 `high.webp`；TCGdex 每集約 3% 的卡只有 `high.webp`，縮圖 404 或連線中斷時 `SearchResults` 以 onerror 改載大圖，僅切換一次。
- 普通、非普通卡隨機標為反閃（與原作相同）。
- 查無結果：顯示「找不到這張卡牌，請試試英文名稱」，並保留原作的「Computer Error」卡。
- 搜尋結果的卡牌同樣可捕捉。

### 6.3 中文搜尋

訪客可直接輸入繁體中文寶可夢名稱。流程：

1. **判斷模式**：輸入含任何 CJK 字元即進入中文模式，否則走 §6.2 的英文流程。中文模式最少 2 字即可查詢（超夢、快龍等兩字名很常見）。
2. **查譯名對照**：在 `pokemonNames.json` 中比對 `zh` 與 `aliases`（含舊譯、簡體），排序為
   完全相符 > 前綴相符 > 子字串相符，最多取 **8** 隻。
3. **組查詢**：每個英文名一個 GraphQL 別名區塊，一次請求送出，結果合併去重。
   2026-09-06 實測：`name: "Pikachu"` 會同時命中 Pikachu V、VMAX、V-UNION 等衍生卡；
   含 `'`、`.`、空白的名稱（Farfetch'd、Mr. Mime）以 JSON 字串跳脫後可正常查詢。
4. **顯示**：結果卡牌名稱下方以小字顯示對應中文名（由英文名反查對照表，去掉 V、VMAX 等後綴後比對）。
5. **查無對照**：顯示「譯名對照裡找不到「{輸入}」，請確認名稱或改用英文」，不呼叫 API。
6. **API 重試**：對 5xx 以 1 秒、2 秒、4 秒退避重試三次，之後才顯示錯誤卡。
   5xx 回應常缺 CORS 標頭，瀏覽器會以網路錯誤拋出，一併視為可重試；單次請求逾時 10 秒。

placeholder 改為：「輸入寶可夢名稱，例如：皮卡丘 或 Pikachu」。

### 6.4 閃卡類型點選搜尋

- 搜尋框右側有「選擇閃卡類型」按鈕，輸入框聚焦或按下按鈕時在搜尋框下方彈出面板，列出可點選的卡種
  （與 18 個展示區同名同序）：普通與非普通、反閃卡、閃卡、宇宙閃卡、驚奇稀有、光輝寶可夢、訓練家畫廊閃卡、寶可夢 V、
  寶可夢 V 全圖、寶可夢 V 異圖、VMAX、VMAX 異圖、VSTAR、訓練家全圖、彩虹稀有、黃金秘密稀有、訓練家畫廊 V 與 VMAX、閃色寶藏。
  異圖依凍結區 `alternate-arts.json` 的 id 清單判斷；宇宙閃卡 TCGdex 沒有欄位，只列凍結區 `promos.json` 中 style 為 Cosmos
  的 84 張促銷卡，以 `card(id)` 逐張查詢（非促銷的宇宙閃卡，例如閃色寶藏集的博士的研究，無法列出）。兩個 json 只讀取不修改。
- 點選即查詢，不需輸入文字；再點同一個取消。可與名稱輸入合併（在該類型裡找某隻寶可夢）。
- 定義在 `src/config/tcgdex.js` 的 `FOIL_TYPES`：每個類型有一組 TCGdex 篩選條件（rarity 為子字串比對，
  suffix、stage、category、trainerType 為精確比對，每組一個 GraphQL 別名區塊），取回後再以轉換後的稀有度過濾
  （彩虹與金卡、畫廊集、閃色寶藏在 TCGdex 沒有獨立欄位）。單一區塊最多取 100 張，再排序取前 36。
- 面板開合以外部點擊與 Escape 關閉，不用 blur（iOS 點按鈕不會取得焦點）。手機時面板撐滿 TopBar 寬度。
- 結果區頂端顯示「閃卡類型：{名稱}」與取消按鈕；點選「反閃卡」時結果全部標為反閃。

#### 譯名對照資料

- **來源**：`docs/pokemon-language-list.md`，神奇寶貝百科「寶可夢列表（在其他語言中）」頁面轉存，
  CC BY-NC-SA 3.0，README 已致謝。頁面表格欄位數不固定（原表有 rowspan），解析規則：
  以「含假名字母（ぁ-ゖ、ァ-ヺ，不含間隔號「・」）的儲存格」定位日文欄，其右一格為英文名，
  其左側所有 CJK 字串為中文名，第一個為正式名，其餘為別名。
- **可編輯版本**：`docs/pokemon-names.csv`（UTF-8 with BOM，Excel 可直接開），欄位
  `no, zh_tw, en, aliases`（別名以 `|` 分隔）。**要修改譯名請改這個檔**，不要改 md 或 json。
- **建置**：`npm run build:names` 執行 `scripts/build-names.mjs`，讀 CSV 產生
  `src/config/pokemonNames.json`（精簡格式 `[{n,zh,en,a:[…]}]`，約 66KB，gzip 後約 25KB，
  以動態 `import()` 在第一次搜尋時才載入；英文搜尋也載入，以便結果標注中文名）。
- **驗證結果（2026-09-06）**：1025 隻全數解析，加上編號 0000「寶可夢」共 1026 筆，
  962 個別名，中文正式名無重複，別名不與其他寶可夢正式名衝突。
- **已知限制**：對照表只有寶可夢本體名稱，訓練家卡（例如「瑪俐」）、地區型態（「伽勒爾 大蔥鴨」）
  與招式名不在範圍內；地區型態輸入「大蔥鴨」仍會命中 Galarian Farfetch'd。

## 8. 真新鎮場景

### 目前版本：三地連續飛行（2026-09-06）

依使用者提供的真新鎮、一號道路、常磐市參考圖，將同風格的 3D 幾何地景沿南北方向連接。
此更新取代下方舊版固定俯視 OrthographicCamera 的村莊構圖；卡牌與介面規格保持原設定。

- `src/scene/region.js`：一號道路折返土路、長草區、矮土坡、花叢與樹列；常磐市白色街道、
  紅頂寶可夢中心、藍頂商店、綠頂民宅、道館、池塘與西側岩壁。
- `src/scene/journey.js`：Catmull–Rom 飛行路徑，鏡頭由南向北從 z=27 到 z=-143，
  高度約 6–8 單位，前視 24 單位、僅輕微向下看，呈現無人機低空平視。
- `src/scene/clouds.js`：世界座標的立體雲層，InstancedMesh 共用球體幾何，一次繪製所有雲團；
  與地景共用透視鏡頭，遠近位移與大小由投影決定。風以累計有效幀時間緩慢移動，
  不再使用舊版螢幕雲圖、scrollFactor 位移與貼圖循環；reduced-motion 停止飄移。
  雲形每次頁面載入取得隨機種子，同次瀏覽維持不變，生成薄雲、積雲、斷續雲團與偏側隆起，獨立變化寬厚比例、隆起數與方向；
  不規則曲面搭配平滑法線及隨日夜變化的柔和補光，減少重複橢球與過硬陰影。
- `village.js`：使用 PerspectiveCamera，桌機 56°、直向螢幕 72° 視角，遠景霧化。
  地形與物件材質仍共用並合併繪製，低效能模式減少長草密度與樹冠細分。
- `town.js`：以目前展示區內的相對捲動位置計算全程進度，ResizeObserver 追蹤延遲掛載後的版面。
  鏡頭以時間相關插值平滑追蹤；反向捲動沿原路返回；搜尋時保留原有旅程位置。
- 卡牌放大時凍結飛行與視差；reduced-motion 固定在真新鎮，不播放捲動飛行及波紋。
- 驗證：build、check（0 error、既有 1 warning）、路徑／捲動／模型測試通過；

### 8.1 圖層設定檔 `src/config/town.js`

單一 three.js `OrthographicCamera` 場景，每層一個 `PlaneGeometry` + `MeshBasicMaterial`（透明貼圖）。

```js
{
  key: 'houses',
  src: '/town/houses.png',   // 空字串或檔案不存在時，用佔位幾何體
  width: 2400, height: 800,  // 素材像素尺寸，用來算比例
  depth: 0.6,                // 0 最遠（天空）到 1 最近（前景草）
  parallax: 0.35,            // 滑鼠 / 陀螺儀位移係數
  scrollFactor: 0.2,         // 頁面捲動位移係數
  anchor: 'horizon',         // top 貼視窗頂、bottom 貼視窗底、horizon 下緣貼地平線、horizon-top 上緣貼地平線
  y: -0.09,                  // 相對視窗高度的偏移，正值向上
  widthFrac: 0.55,           // 顯示寬度相對視窗寬度；全寬圖層預設 1.15 留視差空間
  x: -0.26                   // 水平偏移，相對視窗寬度
}
```

地平線 `HORIZON = 0.42`（相對視窗高度、從底部起算）。天空 shader 同時畫出地平線以下的地面漸層，
因此任何長寬比都有地面，田野與前景草只是加在上面的裝飾層。星星只出現在地平線以上。

預設圖層（由遠到近）：sky（漸層，不需素材）、clouds-far、moon、treeline（遠景樹列）、haze、fields（草地點紋、沙路、花圃、柵欄）、lab（大木研究所）、houses、houses-night、pond（池塘與柵欄）、clouds-near、trees-near（左右框樹）、foreground-grass。
佔位圖造型與配色參考遊戲版真新鎮俯視圖（`town.jpeg`，僅作參考不入庫）：橘紅屋頂灰藍牆民宅、黃磚牆灰瓦頂研究所、圓頂樹。素材清單見 `public/town/README.md`。

### 8.4 降級與暫停

| 條件 | 行為 |
|---|---|
| `document.hidden` | 暫停 render loop |
| `prefers-reduced-motion: reduce` | 靜態渲染一幀，不跑 loop，雲不動，粒子關閉 |
| `navigator.deviceMemory < 4` 或手機 | 貼圖上限 1024px，雲數量減半，粒子減半 |
| WebGL 不可用 | 不掛 canvas，body 以 CSS 漸層天空代替 |
| 使用者放大卡牌 | 持續 render，但暫停視差（避免與卡牌傾斜視覺打架） |

## 9. 互動規格

### 9.1 捕捉與我的圖鑑

- 觸發：任一卡牌進入 `active`（監聽凍結區 `activeCard` store），`CaptureButton` 於畫面底部中央淡入（手機 64px，桌機 56px）。
- 點擊精靈球：
  1. `pokeball.js` 生成精靈球，從按鈕位置沿拋物線飛到卡牌中心，約 600ms。
     實作採 DOM 元素 + Web Animations API，而非原設計的 three.js 場景：場景 canvas 在頁面底下，
     畫在場景裡會被放大的卡牌遮住。卡牌中心取 `.card__rotator` 的 `getBoundingClientRect()`（含 transform）。
  2. 到達後精靈球放大再縮小模擬吸入，卡牌 DOM 不動。
  3. 按下時先依捕捉率擲骰決定成敗，動畫只負責演出。成功：晃動三下，每下 350ms，最後閃星粒子約 800ms。
     失敗：晃 1 到 3 下（隨機）後精靈球彈開，白色閃光環擴散、灰色煙霧散開約 500ms，卡牌跑掉；按鈕晃一下並顯示「跑掉了！再試一次」1.5 秒，不寫入圖鑑，可立刻再擲。
  4. 成功時 `pokedex.add(card)`，TopBar 計數 +1 並彈跳一次，顯示「捕捉成功！」1.5 秒。
- 捕捉率依稀有度字串分級，預設文案顯示「捕捉這張卡牌 · 成功率 N%」：

  | 稀有度（不分大小寫，關鍵字比對） | 成功率 |
  |---|---|
  | Common、Uncommon | 90% |
  | Rare、Rare Holo、Cosmos、Trainer Gallery、稀有度未知 | 70% |
  | Amazing Rare、Radiant Rare、Rare Holo V、Rare Holo VSTAR | 55% |
  | Rare Ultra、Rare Holo VMAX | 45% |
  | Rare Rainbow、Rare Secret、Rare Shiny | 30% |
- 已捕捉的卡牌放大時，按鈕顯示「已捕捉」，再點一次「放生」，直接移除，不播動畫。
- 卡牌收合（`activeCard` 變 undefined）時按鈕淡出，進行中的動畫照常播完。
- 凍結區 `Card.svelte` 以 `on:blur` 收合卡牌，按下精靈球會先讓卡牌失焦。`CaptureButton` 在 pointerdown/mousedown 取消預設行為讓焦點留在卡牌；鍵盤 Tab 到按鈕時則在 capture 階段攔下卡牌的 blur。不改凍結區。
- 圖鑑資料：`localStorage['pokedex.v1']`，陣列，每筆 `{ id, name, set, number, sectionId?, capturedAt }`。
- 圖鑑抽屜：桌機右側滑入 360px，手機底部滑出 70vh。縮圖用 `https://images.pokemontcg.io/{set}/{number}.png`（小圖），不重新渲染閃卡。點縮圖：有 `sectionId` 則捲到該展示區，否則填入搜尋框搜尋該名稱。
- 標題：「我的圖鑑」，計數文案：「已捕捉 N 張」。空狀態：「還沒有捕捉到任何卡牌，放大一張卡牌試試看！」

### 9.4 屬性天氣 `src/config/weather.js`

#### 3D 場景整合（已實作，2026-09-07）

- 已確認方向：以自然天氣為主，幻想現象為輔；屬性天氣融入 3D 背景，可由天空、雲層、光照與地景共同呈現。
- 日夜搭配：保留目前日夜時段，屬性天氣依時段調整光色與亮度，不將夜晚切換成白天。例如夜晚火屬性呈暖橘光與熱浪、無色呈晴朗星空、龍屬性降低金色光束亮度。
- 持續時間：放大卡牌時切換至對應屬性天氣，收合後保留，直到放大另一張卡牌；放大無屬性資料的卡牌則恢復原景。捲動穿越三地時維持目前屬性天氣。
- 重新整理：不記住上次的屬性天氣，頁面重新載入後恢復原景，依目前日夜循環設定呈現；放大卡牌後再切換天氣。
- 屬性選擇：雙屬性卡牌取資料中的第一屬性（`types[0]`），不混合兩種天氣，也不提供屬性選擇介面。
- 手機呈現：保留所有屬性的主要特色，減少雨滴、飄葉與光球等數量，簡化熱浪與地面濕亮反光；保留天色、雲層及主要地景反應，以維持捲動飛行流暢。
- 切換過渡：約 2 秒平滑過渡，協調雲層、光照、地景反應及飄落物等變化。例如水切火時雨勢逐漸停止、雲層變薄、光線轉暖，再浮現熱浪。快速切換卡牌時由當前呈現狀態轉向最後一張卡牌的天氣，不排隊播放。
- 減少動態效果：保留各屬性的靜態天色、雲層與霧色，停用飄落物、熱浪扭曲、氣浪及閃電；其餘場景動畫仍依 §8.4 停用。

空間與互動邊界：

- 天氣使用地景的世界座標與透視鏡頭，遵守建築遮擋；雨滴到達屋頂或地面即消失，池塘漣漪只出現在水面。熱浪只扭曲 3D 背景，不影響卡牌與文字。
- 放大卡牌只凍結鏡頭與視差，天氣仍持續；收合、捕捉成功或失敗、搜尋及展示區卸載不重置天氣。
- 切換日夜保留目前屬性，依新時段重新混合光色；日夜過渡沿用 1.2 秒，屬性過渡約 2 秒。減少動態模式直接套用靜態結果。
- 屬性切換沿用本次載入的隨機雲形，平滑改變厚度、密度與顏色，不重新洗牌。未知屬性與無屬性資料同樣恢復原景。
- 頁面隱藏時暫停天氣時間，恢復後不補播累積閃電；WebGL 不可用時沿用 CSS 背景降級。

- 手機粒子數約為桌機 42%，火舌、積水及波紋同步減量；所有屬性的主要辨識效果保留。日常池塘水紋改為合併幾何與共用動畫，維持原有少於 100 個場景繪製物件的檢查。
- 減少動態時停用飄落物、火舌、氣浪、閃電、熱浪與草木形變；保留靜態霧、積水、銀霜與環境光。快速切換仍由當前權重接續約 2 秒過渡，返回原景後清除效果。

## 15. 151 系列整合（2026-09-09）

原作者另有 [pokemon-cards-151](https://github.com/simeydotme/pokemon-cards-151)（GPL-3.0）專案，以不同的 CSS 與元件實作朱紫「151」系列的閃卡效果。本節以最小改動把它併入旅程，作為第 19 站；搜尋暫不納入（見 §15.5）。

### 15.1 已驗證的前提

- 素材：同一個 CDN，但基底為 `https://poke-holo.b-cdn.net/foils/151`，路徑格式為 `foils/sv3-5_en_{三位卡號}_{ph|std}.foil.webp` 與 `etches/sv3-5_en_{三位卡號}_std.etch.webp`。本站 10 張卡全部驗證 200。
- 元件：151 版 `Card.svelte` 與凍結區版本差 221 行，多了 `card__glitter` 與 `card__glare2` 兩層與不同的 CSS 變數；凍結區的 `Card` 與 `CardProxy` 無法渲染 151 效果。`helpers/Math.js`、`stores/activeCard.js`、`stores/orientation.js` 兩邊逐位元組相同，直接共用。
- CSS：兩邊的 `cards.css`、`base.css`、`regular-holo.css` 差異大，且共用 `.card` 與 `data-rarity="rare holo"` 選擇器，全域同時載入會互相覆蓋，必須作用域化。
- 資料：151 版 `cards.json` 207 張，pokemontcg.io 格式，與卡牌登錄表相容，只差 `set` 為物件。圖片沿用 `images.pokemontcg.io`，抽樣驗證可用。

### 15.7 搜尋跟隨系列（2026-09-10）

- 搜尋只在目前系列內找：`tcgdex.js` 的查詢條件依系列帶入 `id: "swsh"` 或 `id: "sv03.5"`，集號對照表加入 `sv03.5` 對應 `sv3pt5`。
- 稀有度依集號分流：151 的 TCGdex 字串（`Double rare`、`Illustration rare`、`Ultra Rare`、`Special illustration rare`、`Hyper rare`）轉成 pokemontcg.io 的大小寫，`ex` 後綴加入 subtypes；劍盾規則不變。
- 閃卡類型面板依系列顯示：劍盾 18 種不變，151 為 10 種且 id 與 151 站點相同（`151-common` 到 `151-hyper`）。`Illustration rare` 是子字串會連特別插畫稀有一起命中，前端再以完全相符過濾；大師球反閃 TCGdex 沒有欄位，改以 8 個固定卡號逐張查詢。
- 面板顯示目前系列：搜尋面板標題列、閃卡類型彈窗標題與結果統計都帶系列名。切換系列時清空搜尋。
- 搜尋結果放大沿用 `JourneyCard` 的集號判斷；151 的反閃、大師球由 `foils151.js` 依卡號決定。
- 面板內不放系列切換，避免第三個切換入口；切換仍在開場畫面與旅程地圖。
