# 真新鎮場景素材清單

把素材放進這個資料夾，並在 `src/config/town.js` 對應圖層填上 `src` 檔名即可。
缺少的圖層會自動用佔位幾何體代替，不影響介面運作。

## 通用要求

- 地平線固定在視窗高度 42% 處（從底部起算），山、民宅、研究所都貼著地平線擺放；地平線以下由程式畫地面漸層。

- 格式：去背 PNG（天空不需要，程式用漸層畫）。
- 寬度至少 2400px，高度依內容；程式會依 `width/height` 等比縮放。
- 圖層左右兩端請可平鋪或留透明，視差移動時邊緣才不會露白。
- 風格：動畫版真新鎮，柔和色調，無文字。造型可參考專案根目錄的 `town.jpeg`（遊戲版俯視圖，只作參考）。
